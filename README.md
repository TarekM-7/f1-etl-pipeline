# f1-etl-pipeline

An ETL pipeline that processes Formula 1 race data, calculates driver career statistics, and loads the transformed results to AWS S3 for analytical querying with DuckDB.

## Project Overview

This project uses historical Formula 1 race data from the Ergast dataset to track driver performance over time. The ETL pipeline extracts race results, transforms them into yearly driver level metrics, and calculates statistics such as average finishing position and races entered per season. The resulting dataset enables analysis of how a driver's performance evolved throughout their career.

## Tech Stack

- **Python** — core pipeline language
- **Pandas** — data extraction and transformation
- **Boto3** — AWS SDK for uploading to S3
- **DuckDB** — in-process SQL queries against CSV files
- **python-dotenv** — environment variable management
- **SQL** — analytical queries
- **AWS S3** — cloud data lake storage

### Extract

The pipeline reads raw Formula 1 data from CSV files containing race results, driver information, and season data. Relevant datasets are loaded into memory and prepared for transformation.

### Transform

The data is cleaned, joined, and aggregated to create driver-level performance metrics. For each driver and season, the pipeline calculates statistics such as average finishing position and races entered, enabling analysis of performance trends throughout a driver's career.

### Load

The transformed dataset is written to the `data/processed` directory and uploaded to an AWS S3 bucket. The resulting files can be queried directly using DuckDB for further analysis.

## How to Run

### Prerequisites

- Python 3.8+
- An AWS account with an S3 bucket created
- The [Ergast F1 dataset](https://www.kaggle.com/datasets/rohanrao/formula-1-world-championship-1950-2020) downloaded from Kaggle

### Setup

1. Clone the repository

```bash
   git clone https://github.com/TarekM-7/f1-etl-pipeline.git
   cd f1-etl-pipeline
```

2. Create and activate a virtual environment

```bash
   python -m venv venv
   source venv/bin/activate  # Windows: venv\Scripts\activate
```

3. Install dependencies

```bash
   pip install -r requirements.txt
```

4. Configure environment variables

```bash
   cp .env.example .env
```

Fill in your AWS credentials in `.env`.

5. Place the raw CSV files in `data/raw/`
   - `results.csv`
   - `drivers.csv`
   - `races.csv`

### Run the pipeline

```bash
python main.py
```

### Run a query

```bash
python sql/query_runner.py
```
